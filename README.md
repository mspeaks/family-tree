# Family Tree App

A web-based application for creating and visualizing family trees. Built with HTML, CSS, and JavaScript.

## Features
- Interactive family tree visualization
- Add and edit family members
- Connect family relationships
- Responsive design

## Live Demo
Visit the live demo at: [https://mspeaks.github.io/family-tree/](https://mspeaks.github.io/family-tree/)

## Local Development
1. Clone the repository:
   ```bash
   git clone https://github.com/mspeaks/family-tree.git
   ```
2. Open `index.html` in your web browser
3. Start editing!

## Technologies Used
- HTML5
- CSS3
- JavaScript
- D3.js (for tree visualization)
